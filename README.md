# Color Changer App
This is a simple web project that allows users to change the website's background color and header using interactive buttons.

## Features
- Red background
- Blue background
- Green background
- Yellow background
- Random background
- Reset background

## Technologies Used 
- HTML
- CSS
- JavaScript

## Purpose
This project was created to practise JavaScript DOM manipulation, event handling, and dynamic styling.
